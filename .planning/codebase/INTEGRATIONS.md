# External Integrations

**Analysis Date:** 2026-10-05

## APIs & External Services

**Market data providers (browser fetch, user-supplied keys):**
- FMP - `src/data/api/fmp-api.ts`
  - Endpoint: `https://financialmodelingprep.com/stable/historical-price-eod/full?...&apikey=${this.apiKey}`
  - Auth: user key stored in `src/data/schemas/settings.ts` as `ApiKeys.fmp`
- EODHD - `src/data/api/eodhd-api.ts`
  - Endpoint: `https://eodhd.com/api/eod/${fullSymbol}?from=${startDate}&to=${endDate}&api_token=${this.apiKey}&fmt=json`
  - Auth: `ApiKeys.eodhd`
- Alpha Vantage - `src/data/api/alpha-vantage-api.ts`
  - Endpoint: `https://www.alphavantage.co/query?function=TIME_SERIES_DAILY_ADJUSTED&symbol=${symbol}&outputsize=full&apikey=${this.apiKey}`
  - Auth: `ApiKeys.alphavantage`
- Tiingo - `src/data/api/tiingo-api.ts`
  - Endpoint: `https://api.tiingo.com/tiingo/daily/${symbol}/prices?startDate=${startDate}&endDate=${endDate}`
  - Auth: `Authorization: Token ${this.apiKey}`
- Yahoo Finance fallback - `src/data/api/yahoo-api.ts`
  - Endpoint: `https://query1.finance.yahoo.com/v8/finance/chart/${symbol}?period1=...&period2=...&interval=1d`
  - Auth: none; `YAHOO_DISCLAIMER` states the API is unofficial and unstable
- CORS proxy helpers - `src/data/api/cors-proxy.ts`
  - Proxy types: `none`, `allorigins`, `corsproxy`, or custom via `src/data/schemas/settings.ts`
  - Used by `src/data/api/base-api.ts` before every outbound request

## Data Storage

**Databases:**
- IndexedDB via Dexie (`src/data/db.ts`)
  - Database name: `evelo`
  - Tables: `portfolios`, `marketData`, `settings`, and `customMarketData`
  - Access pattern: `db.portfolios`, `db.marketData`, `db.settings`, and `db.customMarketData`
  - Write/read flows: `src/data/services/portfolio-service.ts`, `src/data/services/market-data-service.ts`, `src/data/services/settings-service.ts`, and `src/data/services/custom-data-service.ts`

**File storage:**
- Local browser storage only; no remote object storage or server-side persistence is present in the repo
- Bulk import/export is file-based (`src/data/services/bulk-import-service.ts`, `src/data/services/bulk-export-service.ts`) using CSV or JSON payloads

**Caching:**
- `src/data/services/market-data-service.ts` caches market data in `db.marketData` for `CACHE_DURATION_DAYS = 7`
- Cache key is `[symbol+source]` and stores `CachedMarketData` entries with date ranges and fetched timestamps

## Authentication & Identity

**Auth Provider:**
- Custom user-managed API keys, not OAuth or an external identity provider
  - Implementation: `src/data/schemas/settings.ts` defines `ApiKeys` and `UserSettings`; `src/components/ui/settings-panel.ts` collects and persists the keys via `setApiKey`/`clearApiKey`
  - Storage: `db.settings` in IndexedDB
  - No `.env`-backed secret handling is used in the source tree

## Webhooks & Callbacks

**Incoming:**
- None detected

**Outgoing:**
- Market data requests are outbound HTTP `fetch()` calls from `src/data/api/base-api.ts` and `src/data/api/*.ts`
- Worker progress callback is a proxy callback in `src/simulation/index.ts` and `src/simulation/simulation.worker.ts`, not a network callback

## Worker boundaries and data exchange

**Simulation worker:**
- `src/simulation/worker-loader.ts` creates the worker and wraps the remote API with `Comlink`
- `src/simulation/simulation.worker.ts` exposes `simulate`, `cancel`, and `healthCheck`
- `src/simulation/index.ts` calls `w.simulate(...)` and passes `Comlink.proxy(onProgress)` for progress streaming
- The worker returns a `SimulationOutput` with `terminalValues: Float64Array`; `Comlink.transfer(result, [result.terminalValues.buffer])` is used for zero-copy transfer

**Local data exchange:**
- `src/data/services/market-data-service.ts` reads/writes cached daily-return arrays in `db.marketData`
- `src/data/services/bulk-import-service.ts` parses CSV/JSON payloads into structured asset records
- `src/data/services/bulk-export-service.ts` emits CSV/JSON text for export/download
- `src/components/ui/settings-panel.ts` persists user API keys and CORS proxy configuration through `setApiKey`, `clearApiKey`, and `saveSettings()`

To satisfy the locked requirement that each genuinely new symbol has an explicit reviewed destination, add optional `newSymbolPartitions` to the manifest contract, constrained to `stocks.json` or `indices.json`; runtime semantics require exactly one route for every genuinely new source symbol and reject irrelevant/unknown route keys.

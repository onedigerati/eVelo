## Trust Boundaries

| Boundary | Description |
|---|---|
| Review claims → maintainer decision | A checksum proves byte identity, not the truth of methodology, attribution, reviewer authority, or exception claims. |
| Git history → rollback | A path-limited restore can discard work if the current diff is not inspected or unrelated paths are included. |
| Runbook command examples → maintainer shell | Repository-relative, quoted variables keep examples portable and avoid machine-specific paths. |

| T-03-08 | Tampering | Git rollback commands | high | mitigate | Require examining the current diff and restoring only the exact preset paths changed by apply from the recorded pre-apply commit; test the required runbook wording. |
| T-03-SC | Tampering | npm installs | high | mitigate | No dependency install is planned; if an install is later proposed, require the package-legitimacy audit and blocking human review for any `[ASSUMED]`/`[SUS]` package. |

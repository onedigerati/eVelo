<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Maintainer-selected artifacts → apply CLI | Candidate files and source paths may be stale, edited, malformed, or symlinked; all are untrusted until regenerated and byte-matched. |
| Apply CLI → repository filesystem | Only the internally fixed preset allow-list is writable; caller-controlled paths never become write targets. |
| Maintenance CLI → browser/provider systems | No browser runtime or provider integration is in the apply path; custom data stays on its separate persistence boundary. |
